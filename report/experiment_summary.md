# 基于 Ultralytics 的单缺口、多缺口和截取识别实验小结

## 1. 实验目的

本实验旨在基于 Ultralytics YOLO 目标检测框架，完成对图像中三类目标的自动识别，包括单缺口（`single_gap`）、多缺口（`multi_gap`）以及截取/截断（`truncated`）。通过实验掌握数据集组织、YOLO 标注格式、模型训练验证流程以及实验结果整理方法。

## 2. 实验环境

实验开发语言为 Python，核心框架为 Ultralytics YOLO。主要依赖包括 `ultralytics`、`opencv-python`、`pyyaml`、`numpy`、`pillow` 和 `tqdm`。实验可在 Windows、macOS 和 Linux 环境下运行，脚本统一使用 `pathlib.Path` 管理路径，便于跨平台复现。

## 3. 数据集设计

数据集采用 YOLO Detection 格式进行组织，按照训练集、验证集和测试集分别存放图像文件，并为训练集和验证集提供同名标签文件。类别编号定义为：`0` 对应单缺口，`1` 对应多缺口，`2` 对应截取/截断。标签文件的每一行包含类别编号及归一化后的边界框参数，便于模型直接读取。

本实验在当前工程中使用了一套代理构造数据：从已有目标检测数据中抽取部分样本，并依据边界框数量与是否贴边的规则重新映射为三类标签。其中，单目标且不贴边样本映射为单缺口，多目标且均不贴边样本映射为多缺口，所有目标均贴边或边界框过大的样本映射为截取/截断。该方法有助于快速完成课程实验流程，但在实验报告中应说明其属于规则派生数据，而非人工精标数据。

## 4. 模型训练方法

实验选用 Ultralytics 提供的轻量化检测模型作为初始权重，默认使用 `yolo11n.pt`，在兼容性不足时可替换为 `yolov8n.pt`。训练阶段通过设置训练轮数、输入尺寸、批大小和设备参数完成模型拟合，并输出最优权重、损失曲线图和混淆矩阵图等结果，用于后续分析。

## 5. 识别流程

完整识别流程包括五个阶段：首先对数据集目录和标签格式进行检查；其次对原始数据进行训练集和验证集划分；然后使用训练脚本完成模型训练；训练结束后通过验证脚本输出 Precision、Recall、mAP50 和 mAP50-95 等指标；最后利用预测脚本对测试图像进行推理，保存带检测框的结果图并输出识别类别、置信度和边界框坐标。

## 6. 结果分析

实验结果主要通过验证指标和可视化图像进行分析。若模型训练充分，`mAP50` 和 `mAP50-95` 能够反映模型在三类目标上的综合检测能力；混淆矩阵可用于观察类别间的误检和漏检情况；预测结果图则可直观展示模型对单缺口、多缺口和截取目标的定位效果。由于当前数据集采用规则派生方式生成，指标结果更适合作为流程验证和课程实验演示依据，而不应直接等同于真实缺口检测任务上的最终性能。

## 7. 常见问题与改进方向

实验中常见问题包括：标签文件与图片文件不同名、类别编号填写错误、坐标未归一化、训练集与验证集分布不均衡以及模型权重下载失败等。后续改进方向主要包括扩充数据集规模、优化类别分布、增加数据增强策略、尝试更高性能模型以及在 GPU 环境下提升训练效率，从而进一步提高检测精度和鲁棒性。
